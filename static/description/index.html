Flous Flow POS Bluetooth Printer

Experimental browser-side BLE receipt printing for Odoo 19 Community

Routes the existing Odoo Point of Sale receipt through a browser Web Bluetooth connection after the cashier selects a configured printer. Odoo remains responsible for the receipt values and payment flow.

Features

  • Per-POS printer profile, manual or automatic mode, connection limits, and explicit native fallback.
  • Browser-side GATT discovery with administrator-entered service and characteristic UUIDs.
  • Bounded raster encoding and ordered chunk transmission behind an explicit ESC/POS compatibility setting.
  • Automatic event deduplication and no automatic resend after uncertain transfer.
  • Safe connection diagnostics and a cashier-initiated test transmission.

Requirements and limitations

  • Odoo 19 Community with Point of Sale, HTTPS, and a browser that exposes Web Bluetooth.
  • Bluefy on iOS is the requested target browser, but compatibility has not been verified.
  • Rongta RPP30 is experimental and hardware-not-verified. Its GATT UUIDs and compatible receipt protocol are not supplied by this addon.
  • No native Safari or Chrome iOS support is claimed. No universal ESC/POS compatibility is claimed.
  • A successful Bluetooth write does not confirm paper output. Confirm at the printer.
  • CPCL and TSPL encoders, device acknowledgements, and validated device-specific settings are not included.

Setup

Install the addon, configure the POS and a company profile, enter manufacturer-confirmed UUIDs, verify the printer protocol, connect from the POS toolbar, and run a test print. Start in manual mode with native fallback enabled.

See the included README, compatibility matrix, deployment guide, and physical hardware test plan for details.
